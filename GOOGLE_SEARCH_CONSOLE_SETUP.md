# Google Search Console Setup Guide

This guide will help you verify your site with Google Search Console and submit your sitemap.

## File Location

The Google verification file `googlef5c90b0ba34f5df5.html` is already placed in the `public/` directory, which is correct. Files in `public/` are served from the root of your website.

After deployment, the file will be accessible at:
- `https://theme.stylofront.site/googlef5c90b0ba34f5df5.html`

## Verification Methods

Your site is set up with **two verification methods**:

### 1. HTML File Method
- File location: `public/googlef5c90b0ba34f5df5.html`
- Accessible at: `https://theme.stylofront.site/googlef5c90b0ba34f5df5.html`
- This is the primary verification method

### 2. Meta Tag Method (Backup)
- Meta tag is added in `app/layout.tsx`
- Content: `googlef5c90b0ba34f5df5`
- This provides an alternative verification method

## Steps to Verify Your Site

1. **Go to Google Search Console**
   - Visit: https://search.google.com/search-console
   - Sign in with your Google account

2. **Add Property**
   - Click "Add Property"
   - Select "URL prefix"
   - Enter: `https://theme.stylofront.site`
   - Click "Continue"

3. **Verify Ownership**
   - Choose "HTML file" verification method
   - Google will look for: `googlef5c90b0ba34f5df5.html`
   - Click "Verify"

4. **Wait for Deployment**
   - Make sure your site is deployed (the file must be live)
   - The file should be accessible at: `https://theme.stylofront.site/googlef5c90b0ba34f5df5.html`
   - If verification fails, wait a few minutes and try again

## Submit Your Sitemap

After verification:

1. **Go to Sitemaps Section**
   - In Google Search Console, click "Sitemaps" in the left sidebar

2. **Add Sitemap**
   - Enter: `sitemap.xml`
   - Click "Submit"

3. **Verify Sitemap**
   - Google will fetch: `https://theme.stylofront.site/sitemap.xml`
   - Wait for Google to process it (may take a few hours)

## Troubleshooting

### Verification File Not Found

1. **Check if file is deployed:**
   - Visit: `https://theme.stylofront.site/googlef5c90b0ba34f5df5.html`
   - If you see the verification content, it's working
   - If you get 404, the deployment might not be complete

2. **Wait for deployment:**
   - After pushing changes, wait 2-5 minutes for GitHub Pages to deploy
   - Check the Actions tab to ensure deployment completed

3. **Clear cache:**
   - Try accessing the file in an incognito window
   - Clear your browser cache

### Sitemap Not Found

1. **Check sitemap URL:**
   - Visit: `https://theme.stylofront.site/sitemap.xml`
   - You should see XML content with your pages

2. **Verify basePath:**
   - Make sure `BASE_PATH` is set correctly (empty for custom domain)
   - Check the build logs to confirm

## Additional Notes

- The sitemap is automatically generated by Next.js
- Both will be available after deployment
